# SpireLike — AI 驱动的 Roguelike 卡牌构筑游戏

> **引擎**：Godot 4.7 | **风格**：像素 2D | **类型**：Deckbuilder Roguelike  
> 灵感来自《杀戮尖塔》，完全由 AI 辅助开发

---

## 快速开始

1. 用 **Godot 4.7** 打开 `project.godot`
2. 点击运行（F5）→ 主菜单 → 「开始冒险」或按 `Enter`
3. 在地图上选择路线 → 进入战斗 → 打出卡牌 → 击败敌人 → 继续前进
4. 通过三层关卡、击败最终 Boss 即为胜利

---

## 游戏玩法

### 战斗系统
- 每回合 **3 点能量** + 抽 **5 张牌**，手牌上限 10 张
- 打出攻击牌造成伤害，技能牌获得格挡，能力牌整场持续生效
- 格挡每回合清零（仅玩家），敌人格挡持续至下一轮敌人行动前
- 查看敌人意图决定出牌策略（意图 100% 准确）

### 卡牌
| 类型 | 颜色 | 说明 |
|------|------|------|
| 攻击牌 | 红 | 造成伤害 |
| 技能牌 | 蓝 | 获得格挡 / 抽牌 / 上 Buff |
| 能力牌 | 黄 | 整场战斗持续生效（使用后消耗） |

当前卡池：打击、防御、重击、铁壁、剑柄打击、战斗怒吼等 8 张

### Buff / Debuff
| 效果 | 说明 |
|------|------|
| 力量 | 每层 +1 攻击伤害 |
| 易伤 | 受到伤害 ×1.5 |
| 虚弱 | 造成伤害 ×0.75 |
| 中毒 | 每回合失去 X 生命，每回合递减 1 层 |

### 地图
- **DAG（有向无环图）**，8 行 × 3 列网格
- 每种房间类型用颜色和图标区分
- 路线单向不可逆，2-3 条路径汇聚到 Boss

| 房间 | 说明 |
|------|------|
| ⚔ 战斗 | 普通敌人，胜利获得金币 |
| ⭐ 精英 | 高强度敌人，更多金币 |
| 💀 首领 | 每层终点，击败进入下一层 |
| 🛒 商店 | （待实现） |
| 🔥 休息 | 回复 30% 生命 |
| 📦 宝箱 | （待实现） |
| ❓ 事件 | （待实现） |

## 控制

| 操作 | 按键 |
|------|------|
| 打出卡牌 | 鼠标左键点击 |
| 悬停卡牌 | 放大 + 上浮预览 |
| 结束回合 | 点击按钮 / `E` 键 |
| 开始游戏 | 点击按钮 / `Enter` |

| 按键 | 功能 |
|------|------|
| `K` | 秒杀当前敌人 |

| `G` | +100 金币 |

## 项目结构

```
spirelike/
├── assets/art/                    # 美术资源（像素风占位图，替换即用）
│   ├── backgrounds/               # 背景图
│   ├── cards/                     # 卡牌底板
│   ├── characters/warrior/        # 战士精灵
│   ├── enemies/                   # 敌人精灵
│   └── ui/                        # UI 元素（图标/意图/地图节点）
├── scenes/                        # Godot 场景文件
│   ├── main_menu.tscn             # 主菜单
│   ├── battle/battle_scene.tscn   # 战斗场景
│   ├── cards/card_scene.tscn      # 卡牌 UI 组件
│   └── map/map_scene.tscn         # 地图场景
├── scripts/                       # GDScript 脚本
│   ├── autoload/                  # 全局单例
│   │   ├── combat_state.gd        # 战斗核心：回合/牌堆/伤害/能量
│   │   └── game_state.gd          # 全局持久：牌组/HP/金币/楼层
│   ├── cards/                     # 卡牌系统
│   │   ├── card_resource.gd       # 卡牌数据 Resource 类
│   │   ├── card_ui.gd             # 卡牌 UI 交互
│   │   └── card_database.gd       # 卡牌数据库
│   ├── enemies/
│   │   └── enemy_resource.gd      # 敌人数据 Resource 类
│   ├── battle/                    # 战斗
│   │   ├── battle_manager.gd      # 战斗流程控制 + 手牌布局
│   │   └── enemy_battle.gd        # 敌人显示（HP/状态/意图）
│   ├── map/                       # 地图
│   │   ├── map_data.gd            # MapNodeData 数据结构
│   │   ├── map_floor.gd           # MapFloor 楼层管理
│   │   ├── map_generator.gd       # DAG 地图生成算法
│   │   ├── map_manager.gd         # 地图流程控制 + 连线绘制
│   │   └── map_node_ui.gd         # 地图节点交互
│   ├── relics/
│   │   └── relic_resource.gd      # 遗物数据 Resource 类
│   └── ui/
│       └── main_menu.gd           # 主菜单逻辑
└── resources/                     # .tres 数据资源（可视化编辑）
    ├── cards/                     # 卡牌数据
    ├── enemies/                   # 敌人数据
    ├── relics/                    # 遗物数据
    └── ...
```

## 如何替换美术资源

用自己的同尺寸 PNG 覆盖 `assets/art/` 下同名文件即可，无需改代码。

重新生成像素占位图：
```bash
pip install Pillow
python regenerate_assets.py
```

### 资源尺寸参考
| 资源 | 尺寸 | 位置 |
|------|------|------|
| 背景图 | 1280×720 | `backgrounds/` |
| 卡牌底板 | 120×180 | `cards/` |

## 开发环境

- **引擎**：Godot 4.7
- **脚本**：GDScript 2.0（全静态类型）
- **资源格式**：.tres（Godot 原生 Resource 格式）
- **像素渲染**：Nearest 过滤（`default_texture_filter=0`）
- **分辨率**：1280×720，Canvas Items 拉伸模式

### 运行要求
- Godot 4.7+
- Windows / macOS / Linux
