# 暗影尖塔 — Roguelike 卡牌构筑游戏

> **引擎**：Godot 4.7 | **风格**：像素 2D | **类型**：Deckbuilder Roguelike  
> 玩法借鉴《杀戮尖塔》(Slay the Spire)，全程由 AI 辅助开发

---

## 快速开始

1. 用 **Godot 4.7** 打开 `project.godot`
2. 点击运行（F5）→ 主菜单 → 「开始冒险」
3. 在地图上选择路线 → 进入战斗 → 打出卡牌 → 击败敌人 → 继续前进
4. 通过三层关卡、击败最终 Boss 即为胜利

---

## 游戏玩法

### 战斗系统
- 每回合 **3 点能量** + 抽 **5 张牌**
- 打出攻击牌造成伤害，技能牌获得格挡，能力牌整场持续生效
- 格挡每回合清零，敌人格挡持续至下一轮
- 敌人意图 100% 准确显示，可在出牌前查看

### 卡牌
| 类型 | 颜色 | 说明 |
|------|------|------|
| 攻击牌 | 红 | 造成伤害 |
| 技能牌 | 蓝 | 获得格挡 / 抽牌 / 施加 Buff |
| 能力牌 | 黄 | 整场战斗持续生效（使用后消耗） |

当前卡池：23 张，含基础、普通、罕见、稀有

### Buff / Debuff
| 效果 | 说明 |
|------|------|
| 力量 | 每层 +1 攻击伤害 |
| 易伤 | 受到伤害 ×1.5 |
| 虚弱 | 造成伤害 ×0.75 |
| 中毒 | 每回合失去 X 生命，每回合递减 1 层 |

### 地图
- **DAG（有向无环图）**，8 行 × 3 列网格
- 每种房间类型用图标和颜色区分
- 路线单向不可逆

| 房间 | 说明 |
|------|------|
| 战斗 | 普通敌人，胜利获得金币 |
| 精英 | 高强度敌人，更多金币 |
| 首领 | 每层终点，击败进入下一层 |
| 商店 | 用金币购买卡牌和遗物，或删除卡牌 |
| 休息 | 回复 30% 生命 |
| 宝箱 | 免费获得随机遗物 |
| 事件 | 随机叙事事件，多种选项和结果 |

|------|------|

│   ├── cards/                     # 卡牌资源 + 数据库 + UI

## 如何替换美术资源

用自己的同尺寸 PNG 覆盖 `assets/art/` 下同名文件，删除对应 `.import` 文件后重启 Godot 即可。

### 资源尺寸参考
| 资源 | 尺寸 | 位置 |
|------|------|------|
| 背景图 | 1280×720 | `backgrounds/` |
| 卡牌底板 | 120×180 | `cards/` |
| 卡牌插图 | 90×60 | `cards/art/` |
| 角色精灵 | 64×64 | `characters/warrior/` |
| 敌人精灵 | 48–96 px | `enemies/` |
| 遗物图标 | 48×48 | `relics/` |
| UI 图标 | 32×32 | `ui/icons/` |
| 意图图标 | 32×32 | `ui/intents/` |
| 地图节点 | 40×40 | `ui/map_nodes/` |
